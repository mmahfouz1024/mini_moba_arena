# Legends Arena: Mini MOBA (ساحة الأساطير)

لعبة **Mini MOBA** سريعة بنمط **3v3** و **1v1** مستوحاة من ألعاب الحلبات التنافسية (مثل *Mobile Legends*)، مصممة للعمل بسلاسة على الهواتف بوضع العرض الأفقي.

## المزايا الرئيسية
- **4 أبطال بأدوار مختلفة:** مقاتل (Kael)، ساحرة (Lyra)، مدافع/تانك (Vex)، ورامية (Sera).
- **تحكم MOBA كامل:** عصا تحكم يسارية + أزرار مهارات تدعم **السحب للتصويب (Drag-to-Aim)** مع استعراض مدى واتجاه المهارة على الخريطة، بالإضافة لزر الهجوم الأساسي، الشفاء، والعودة للقاعدة (Recall).
- **خريطة متكاملة:** أبراج بدفاع ذكي (تستهدفك عند مهاجمة بطل خصم تحت البرج)، موجات جنود، زعيم النهر وسلحفاة الطاقة، ومتجر معدات داخل المباراة.
- **تصنيف وترقية الحساب:** نظام Ranked (Warrior إلى Mythic) وفتح الأبطال بالذهب المكتسب.
- **ثنائية اللغة:** دعم كامل للعربية والإنجليزية.

## البناء التلقائي عبر GitHub Actions
يتم بناء نسخ الأندرويد تلقائياً على السحابة عبر `.github/workflows/build_android.yml`:
1. كل `push` على فرع `main` يشغل `flutter analyze` و `flutter test` ثم يبني:
   - `app-release.apk` (للتثبيت المباشر على الموبايل)
   - `app-release.aab` (للرفع على Google Play)
2. لتحميل الملفات من GitHub: افتح تبويب **Actions** -> اختر آخر Build ناجح -> قسم **Artifacts**.

### توقيع نسخة النشر الرسمية على جوجل بلاي (اختياري عبر Secrets)
لإخراج `.aab` موقّع بمفتاح الرفع الرسمي الخاص بك، أضف هذه المتغيرات في **Settings -> Secrets and variables -> Actions**:
- `ANDROID_KEYSTORE_BASE64`: محتوى ملف `.jks` محوّلاً إلى Base64
- `ANDROID_KEY_ALIAS`: اسم الـ Alias
- `ANDROID_KEY_PASSWORD`: كلمة مرور المفتاح
- `ANDROID_STORE_PASSWORD`: كلمة مرور الـ Keystore
